# プロジェクト名

静岡理工科大学向け接続案内

> 静岡理工科大学のスクールバス（シャトルバス）の時刻表に対応した,東海道本線（静岡地区）との乗換案内ツールです。


# 公開URL

(http://katsu.hungry.jp/Myapp/index.html)

# 使用技術

- HTML / CSS / JavaScript

# 使い方

1. 公開URLにアクセスします。
2. 出発駅を選択します。
3. 出発時刻を選択します。
4. 接続するスクールバスと電車の乗り継ぎ時刻が一覧で表示されます。

(公開URLを開くだけで利用可能です。)
